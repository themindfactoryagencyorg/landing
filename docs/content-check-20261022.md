# Revisión de contenido · 22 octubre 2026

Comparación con `582e922:index.html`, la última web de `main` usada como base
antes de esta propuesta. Incluye ambos idiomas. El HTML para David aporta los
casos reales; esta revisión contrasta además lo que ya ofrecía la web anterior.

## Orden de lectura aplicado

Portada → qué construimos → casos reales → agente de IA → detalle opcional
MindHub/conexiones → cómo trabajamos → equipo → contacto.

El menú sigue ese orden. La flecha de portada lleva a la oferta; «Ver casos
reales» permite ir directamente a las pruebas. Tras los casos, la invitación a
diseñar la siguiente solución lleva a contacto.

| Contenido anterior | Ubicación actual y decisión |
| --- | --- |
| Software a medida, conexión de herramientas y automatización | Portada y bloque «Lo que tu negocio necesita. Lo construimos.», ahora antes de los casos. |
| Pedidos por WhatsApp, stock en Excel e información que depende de preguntar | Recuperados en el primer bloque de soluciones; eran ejemplos concretos que habían perdido visibilidad. |
| Información compartida, tiempo y visibilidad para decidir | Recuperados junto a esos problemas. Las integraciones explican además que se evita introducir datos otra vez. |
| Ventas y gestión: clientes, pedidos, existencias y facturación | Caso de Qrema, ejemplos del agente y módulos conservados de MindHub. |
| Proyectos, responsables, prioridades y plazos | Caso de Madatuta, ejemplo del agente y módulo de proyectos de MindHub. |
| Equipos en campo conectados con la oficina | Recuperados en «Aplicaciones a medida»; el detalle sigue en el módulo de operaciones. Se presenta como capacidad, sin inventar otro proyecto entregado. |
| Diagrama de conexión, tres etapas y cuatro áreas | Marcado íntegro conservado dentro de «Por dentro». Se mantiene opcional para que el detalle no retrase los casos. |
| Definición de MindHub, seis módulos y demo de venta | Marcado íntegro conservado en el mismo desplegable. |
| Cinco fases, prototipo antes del desarrollo completo y validación con el equipo | «Cómo trabajamos». Se mantiene el acompañamiento y se explicita la formación. |
| Alojamiento, mantenimiento y evolución | Quinto paso del proceso. |
| Minds reutilizables, implantación inicial, cuota mensual y alcance acordado por fases | «Tecnología de gran empresa. A la medida de la tuya.», conservado. |
| Siete perfiles, roles y biografías | Conservados en ES/EN. Se mantienen los retratos aprobados y el comportamiento móvil. |
| Consulta sin compromiso, correo, redes, acceso y páginas legales | Conservados. El contacto explica además diagnóstico, propuesta y estimación. |

Los antiguos tres ejemplos genéricos de soluciones se sustituyen por los tres
casos del documento facilitado. Sus capacidades se mantienen en la oferta y el
detalle; no se presentan los ejemplos genéricos como clientes reales. El agente
mantiene protagonismo sin convertirlo en requisito de toda solución.

No se han añadido cifras de resultados, precios ni plazos garantizados. Las
demostraciones continúan identificadas como ilustrativas y no ejecutan acciones
reales. El chequeo de contenido no acredita resultados comerciales de los casos.
